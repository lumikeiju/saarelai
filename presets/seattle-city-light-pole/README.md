# Seattle City Light Pole

A Seattle City Light pole preset with lighting, pole, and utility-operator fields.

The source file is [`seattle_city_light_pole.xml`](seattle_city_light_pole.xml); it contains the preset metadata and tagging options.

This is separate from the [SCL Poles](../scl-poles/README.md) preset; the source files have different fields and defaults, although their JOSM group and item labels currently match.

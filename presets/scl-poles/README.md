# SCL Poles

A Seattle-area pole preset focused on `light:*=*` tagging, including the `ref:US-WA:SCL:ASSET_ID` field.

The source file is [`scl-poles.xml`](scl-poles.xml). Its initial stable version is `1.0_2026-10-10`.

This is separate from the [Seattle City Light Pole](../seattle-city-light-pole/README.md) preset; the source files have different fields and defaults.

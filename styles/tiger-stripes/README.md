# TIGER Stripes

A JOSM MapCSS paint style that highlights highways carrying TIGER import tags.

The source file is [`tiger-stripes.mapcss`](tiger-stripes.mapcss). It retains its existing MapCSS version (`1.0.0`), publication date (`2025-06-30`), author, and minimum JOSM version (`19418`).
